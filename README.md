# Portfolio — Yoan Ancelly

Portfolio statique minimaliste de Yoan Ancelly, consultant en IA opérationnelle pour PME.

## Contenu

- Positionnement centré sur le flux `demande entrante → qualification → recherche/chiffrage → devis → CRM/ERP`
- Expertise en automatisation et agents IA
- Projets : Sprint IA Utile, passerelle ChatGPT ↔ Hermes, labs Docker pédagogiques
- Contact direct par email et GitHub

## Stack

HTML + CSS uniquement. Aucun framework, build ou dépendance JavaScript.

## Lancer en local

```bash
python3 -m http.server 8000
```

Puis ouvrir `http://localhost:8000`.

## Déploiement

Le projet est compatible tel quel avec GitHub Pages ou tout hébergeur statique.
